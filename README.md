# Магазин компьютерных комплектующих «CoolKit» 💻

Учебный проект, разработанный на первом курсе (ДГТУ, 2024 год). Представляет собой статический многостраничный веб-сайт каталога компьютерных запчастей. Проект создавался для закрепления базовых навыков верстки.

## 🛠 Технологии
* **HTML5** —  разметка страниц.
* **CSS3** — стилизация, Flexbox для карточек товаров.
* **FontAwesome** — иконочный шрифт для бокового меню и элементов интерфейса.

## 📂 Особенности проекта
* Скрываемое боковое навигационное меню.
* Каталог товаров, разбитый по категориям: Видеокарты, Процессоры, Корпуса.
* Карточки товаров с ценами и кнопками заказа.
* Информационные страницы: «Об авторе» и «О фирме».
